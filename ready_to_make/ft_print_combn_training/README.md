# 🔢 Print Combinations Training

Exercises inspired by `ft_print_comb` and `ft_print_combn`: generating ordered digit combinations without duplicates.

## 📚 Focus

Recursion, iteration, ordering rules, and writing characters with `write()`.

## 🎯 Goal

Understand how to build combinations systematically, rather than hardcoding the output.

## 🧪 Practice

Check ordering, separators, first and last combinations, and output for small input sizes.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```
