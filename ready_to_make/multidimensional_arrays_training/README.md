# 🧩 Multidimensional Arrays Training

Practice working with **two-dimensional arrays**, rows, columns, and grid-based problems in C.

## 📚 Focus

Array indexing, nested loops, coordinates, bounds, and traversing grids.

## 🎯 Goal

Get comfortable reasoning about `grid[row][col]` and translating visual problems into C code.

## 🧪 Practice

Test rectangular and square grids, boundary indices, and small examples you can trace by hand.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```
