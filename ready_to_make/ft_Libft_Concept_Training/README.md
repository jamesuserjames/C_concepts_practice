# 📚 Libft Concept Training

Focused practice for the C concepts used while building **Libft** for 42.

## 📚 Focus

Strings, memory operations, allocation, pointer arithmetic, character checks, and linked lists where applicable.

## 🎯 Goal

Recreate standard-library behavior while learning edge cases and safe memory handling.

## 🧪 Testing

Compile standalone drills with strict warnings, compare against the documented contract, and test empty inputs, `NULL` where permitted, and size boundaries.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```

> The exercises are training material and are not themselves a submitted Libft library.
