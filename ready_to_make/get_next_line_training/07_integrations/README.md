# 07 Integrations

Solve functions one at a time. Every `.c` contains a blank implementation, test `main()`, and expected results.

```bash
bash 07_integrations/create_exercises.sh
```

## Exercises

- **`ft_mini_gnl.c`** — Return one allocated line using byte-by-byte reads.
- **`ft_simple_gnl.c`** — Read one line at a time across consecutive calls.
- **`ft_full_gnl.c`** — Build a buffered line reader with retained extra bytes.

> The generator does not overwrite existing `.c` solutions. Implementation functions should be ≤25 lines and use only the allowed functions shown in each file.
