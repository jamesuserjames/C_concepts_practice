# 02 Static Variables

Solve functions one at a time. Every `.c` contains a blank implementation, test `main()`, and expected results.

```bash
bash 02_static_variables/create_exercises.sh
```

## Exercises

- **`ft_static_counter.c`** — Return an incrementing count retained across calls.
- **`ft_static_char.c`** — Return the previous input character (initially NUL), then remember c.
- **`ft_static_buffer.c`** — Add value to a running total preserved across calls.
- **`ft_preserve_state.c`** — Maintain a call counter; reset to zero when reset is nonzero.

> The generator does not overwrite existing `.c` solutions. Implementation functions should be ≤25 lines and use only the allowed functions shown in each file.
