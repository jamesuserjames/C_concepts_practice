# 03 Strings And Memory

Solve functions one at a time. Every `.c` contains a blank implementation, test `main()`, and expected results.

```bash
bash 03_strings_and_memory/create_exercises.sh
```

## Exercises

- **`ft_strlen_gnl.c`** — Count the characters in a NUL-terminated string.
- **`ft_strchr_gnl.c`** — Find the first occurrence of c, including the final NUL.
- **`ft_strdup_gnl.c`** — Allocate a fresh copy of a NUL-terminated string.
- **`ft_strjoin_gnl.c`** — Allocate a new string holding a followed by b.
- **`ft_substr_gnl.c`** — Allocate up to len bytes starting at index start.
- **`ft_free_null.c`** — Free *ptr and set the caller’s pointer to NULL.

> The generator does not overwrite existing `.c` solutions. Implementation functions should be ≤25 lines and use only the allowed functions shown in each file.
