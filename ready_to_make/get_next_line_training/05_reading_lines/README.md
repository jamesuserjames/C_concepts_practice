# 05 Reading Lines

Solve functions one at a time. Every `.c` contains a blank implementation, test `main()`, and expected results.

```bash
bash 05_reading_lines/create_exercises.sh
```

## Exercises

- **`ft_read_line.c`** — Read and allocate one line from a file descriptor.
- **`ft_read_multiple_lines.c`** — Count lines in a file descriptor (including an unterminated last line).
- **`ft_read_long_line.c`** — Count bytes in the first line, even if it exceeds a small buffer.
- **`ft_read_without_newline.c`** — Count bytes up to newline or EOF, excluding newline itself.

> The generator does not overwrite existing `.c` solutions. Implementation functions should be ≤25 lines and use only the allowed functions shown in each file.
