# 🏁 Final Project

These are **empty implementation scaffolds**, not working solutions.

- `mandatory/` contains the three required mandatory files.
- `bonus/` contains the three bonus files with the required `_bonus` suffix.

The starter functions return `NULL` until you implement your own reading and memory management. Do not submit the training `main()` functions or generators as part of your actual project.

Test multiple calls, empty files, trailing newline, no trailing newline, error paths, and BUFFER_SIZE values `1`, `2`, `42`, and `9999` (plus a larger value).
