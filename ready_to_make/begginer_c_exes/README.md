# 🌱 Beginner C Exercises

Small exercises to build confidence with C fundamentals before moving on to larger projects.

## 📚 Focus

Variables, conditions, loops, functions, strings, arrays, and basic input/output.

## 🎯 Goal

Understand **why the code works**, not just how to make the test pass.

## ⚙️ Practice

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```

Replace `exercise.c` with a file from this folder. Work through each exercise, test edge cases, and revisit problems you could not solve unaided.
