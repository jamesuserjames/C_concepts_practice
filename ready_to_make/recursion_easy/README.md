# 🔁 Recursion — Easy

Short exercises for understanding how functions call themselves and how results return through the call stack.

## 📚 Focus

Base cases, recursive cases, return values, counters, and simple mathematical problems.

## 🎯 Goal

Be able to explain **when recursion stops** and **what each call returns**.

## 🧪 Practice

Trace small inputs by hand, then test the base case and one or two larger values.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```
