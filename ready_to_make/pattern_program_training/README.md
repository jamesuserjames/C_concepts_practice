# ✨ Pattern Programming Training

Exercises for building text and number patterns using loops and basic C output.

## 📚 Focus

Nested loops, conditions, spacing, rows, columns, and output formatting.

## 🎯 Goal

Learn to break a visual pattern into small repeatable rules.

## 🧪 Practice

Check alignment, spaces, line breaks, and patterns with a minimum number of rows.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```
