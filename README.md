# 💻 C Concepts Practice

A personal collection of **C programming exercises**, organized by concept and difficulty. Built to practice fundamentals.
## 🎯 Purpose
Learn each concept by **writing the code myself**, then compiling, testing, and improving it. Exercises are deliberately small so I can focus on one problem at a time.

## 📁 Repository Structure

```text
C_concepts_practice/
├── beginner_c_exes/                  # C fundamentals
├── ft_Libft_Concept_Training/        # Libft-related concepts
├── ft_print_combn_training/          # Number combinations & recursion
├── ft_printf_training/              # Formatted output & variadic functions
├── multidimensional_arrays_training/ # 2D arrays and grids
├── pattern_program_training/        # Loops and printed patterns
└── recursion_easy/                  # Recursion fundamentals
```

## ⚙️ Workflow

1. Pick a concept folder and read the exercise instructions.
2. Write the function without changing its test cases.
3. Compile and compare the output with the expected results.
4. Try boundary cases and simplify the solution when possible.

```bash
cc -Wall -Wextra -Werror exercise.c -o exercise.out
./exercise.out
```

> A learning repository, not a finished library. Some files are training templates, others contain working solutions.
